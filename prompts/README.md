# prompts/

論評に使う文面の置き場。ここのファイルを編集すると、次の実行から反映される。

## 作り方

```bash
python main.py prompts
```

既定の文面を書き出す。すでにあるファイルは上書きしない。
既定値に戻すには、そのファイルを削除して再実行するか `--force` を付ける。

## ファイル

| ファイル | 使われるとき |
|---|---|
| `発想.txt` | `--mode 発想` |
| `査読-育成.txt` `査読-標準.txt` `査読-厳格.txt` | `--mode 査読 --severity ...` |
| `採点-育成.txt` `採点-標準.txt` `採点-厳格.txt` | `--mode 採点 --severity ...` |
| `観点.txt` | `--mode 発想` `--mode 査読` |

1 回の実行で読むのは該当する 1〜2 枚だけ。
どれを使ったかは `--out` で書き出す添削ファイルに記録される。

`接続` と `連想` はここを見ない。

## 観点.txt の書式

1 行 1 観点。縦棒で 4 つに区切る。

```
キー | 群 | 使えるモード | 問い
```

- **キー** — 出力に `【削除】` の形で現れる短い名前
- **群** — 観点を散らすときの分類。同じ群からは 1 つしか選ばれない
- **モード** — `発想,査読` のように並べる。片方だけでもよい
- **問い** — モデルに渡す一文。改行は入れられない

`#` で始まる行と空行は無視する。書式が壊れていれば行番号つきでエラーになる。

査読モードに提案型の観点 (本文に無いものを求めるもの) を割り当てないこと。
査読の規則「本文に無い要素について述べない」と矛盾する。
