# センチュリオン

文章を保ったまま、常套から少し外れた語りを返す生成AI。
Qwen2.5-3B-Instruct の上に、盲検で確かめた2つの仕掛けを載せている。

```
$ python -m centurion 古い本を開いたときの手触りを書いて
そうですね、古い本を開いた時の手触りは独特で美しいものがありますよ。
ほんのりと柔らかい紙の風合いが伝わり、手のひらによじれるような光沢。
その歴史を感じさせる厚みと重さ、そして何よりも香ばしい、紙の香り。
```

## 積んであるもの

| 仕掛け | 何をするか | 確かめた結果 |
|---|---|---|
| **分岐点での抑圧** | エントロピーが3.5を超えた箇所でだけ、上位2候補を2.0押し下げる | 盲検36件で**12戦12勝**。素のモデルの読める率58%を100%に。中国語もラテン文字も出さない |
| **流動プロンプト** | 生成ごとに語り方の姿勢2つと禁止語3つを選び直す | 一騎打ちで**20勝12敗** (p=0.108)。有意には届かないが、固定プロンプトが両勝ちしたお題は0だった |

**積んでいないもの** — 未来エントロピーによる重み付け、表現への介入(層24)、
液体回路による姿勢の漂い。いずれも作って測って効かなかった。
経緯は [results/REPORT.md](results/REPORT.md)。

### コマンドライン

```bash
python -m centurion 青色にまつわる話を聞かせて
```

```bash
python -m centurion --chat
```

```bash
python -m centurion 朝の匂いについて書いて 沈黙について書いて --turns
```

`--turns` を付けると前のやり取りを踏まえた一続きの会話になる。
付けなければお題ごとに独立した応答。

| 引数 | 既定 | 意味 |
|---|---|---|
| `--times N` | 1 | 同じお題を何回書かせるか |
| `--no-suppress` | 入り | 分岐点での抑圧を切る。読みやすさが落ちる |
| `--fixed-prompt` | 流動 | プロンプトを固定文にする |
| `--prefill 文字列` | `そうですね、` | 書き出し。空にすると相槌なしで始まる |
| `--tokens N` | 200 | 生成する長さの上限 |
| `--raw` | 切る | 途中で切れた文を残す |
| `--seed N` | — | 同じ種なら同じ文章 |
| `--verbose` | — | そのとき選ばれた姿勢と禁止語も出す |

### Python から

```python
from centurion import Centurion

centurion = Centurion()
print(centurion.say("誰かが置いていった傘の話をして"))

# 会話にすると前のやり取りを覚える
for reply in centurion.converse(["朝の匂いについて書いて",
                                 "雨上がりの舗道の匂いについて書いて"]):
    print(reply)
    print(" 姿勢:", " / ".join(reply.stance))

centurion.forget()      # 記憶を捨てる
```

## 分かっている限界

**目的の後半は達成していない。** 「文章を保つ」は抑圧で達成したが、
「発想の飛躍」は3つの機構を作って測って、いずれも読み手には届かなかった。
いま出てくるのは、読みやすく、常套からわずかに外れた文章であって、
飛躍ではない。

**随筆調に寄る。** 実測112件を数えるとこうなっている。

| | |
|---|---|
| 読み手に語りかける | 112/112 (100%) |
| 名前のある人や場所を含む | 2/112 (2%) |
| 過去の出来事を2文以上語る | 32/112 (29%) |
| 一文目が「Xは〜です」型の一般論 | 47/112 (42%) |

人格には「物語だけを愛する」と書いてあるのに、7割が出来事を語らない。
原因は書き出しの「そうですね、」だと見ている — 相槌のあとに文法的に
自然に続くのは同意・意見・一般化であって、場面ではない。
ただしこれは**未検証**なので、既定は評価時と同じ相槌のままにしてある。
`--prefill` で試せる。

**流動プロンプトの優位は確定していない。** p=0.108 で、有意水準には
届いていない。戻すなら `--fixed-prompt`。
