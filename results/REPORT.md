# センチュリオン Phase 0〜5 報告

2026-08-09

## 要約

**抑圧は「文章を保つ」には効き、「発想の飛躍」には効かない。**

盲検評価で、type5 の設定(エントロピー3.5以上の箇所でのみ上位2候補を -2.0)は
素のモデルの合格率 58% を **100%** に引き上げた。中国語もラテン文字も出さない。
一方、抑圧の強さと轍語彙の出現率の相関は **+0.862**。
抑圧を強めるほど轍語彙は**増える**。

目的の前半は達成、後半は機構ごと差し替えが要る、というのが結論。

---

## Phase 0 — 回路が入力を読めていなかった

type6 の ncps回路が定常状態に落ちていた原因を切り分けた。
定数入力を対照に引くと、観測される揺れの大半は回路自身の自律過渡で、
入力感度はそれを下回っていた。

```
出力      自律過渡   入力感度   感度比
強度      0.0922    0.0338    0.37
幅        0.0318    0.0274    0.86
```

抑圧幅は5つの初期値すべてで**一度も変化しなかった**。
`round()` で整数に量子化していたため、出力の変動が丸めで消えていた。

## Phase 1 — 実測でわかった3つ

Colab で 2012 トークン分の特徴を採取した。

- カスタム LogitsProcessor は **min_p より前**に呼ばれる(全語彙が生きている)。
  つまり抑圧すると `p_max` が下がり min_p の閾値も下がって候補が増える。
  抑圧は自分で自分の効果を増幅していた
- 特徴の分散は十分あった(entropy の標準偏差 1.658)。
  定常状態の原因は入力側ではなかった
- top1 と top5 の相関 0.838。4特徴のうち実質3つしか独立していない
- エントロピー3.5以上は全トークンの **24.4%**。
  type5 の門は「ごく一部」ではなく4分の1で発火していた

## Phase 2 — 回路の修正

4点直した。特徴の標準化と入力射影、出力ゲイン、抑圧幅の `round()` 廃止、
`settle()` による初期状態の定常化。

```
出力      自律過渡   入力感度
ゲート    0.0000    0.5877
強度      0.0000    0.1199
幅        0.0000    0.6264
```

自律過渡が厳密に0になり、入力感度は V1 の 3.5〜18倍になった。

## Phase 3 — 評価関数は作れなかった

24件の人手ラベルに対し、語彙・埋め込み・対数尤度のいずれも判定を再現できなかった。

| 手法 | 一件抜き正答率 | 多数派比 |
|---|---|---|
| 語彙ベースの新語率 | 逆相関 | — |
| 埋め込み距離(単調) | 逆相関 | — |
| 埋め込み距離(帯) | 70.8% | +16.6pt |
| 対数尤度(6統計量) | 62.5% | +8.3pt |
| 組み合わせ(41通り) | 66.7% | +12.5pt |

**× には2種類ある** — 轍型(流暢だが跳んでいない、尤度は高い)と
崩壊型(跳んだが読めない、尤度は低い)。単調な指標はどちらか一方を必ず取り違える。

決定的だったのは、抑圧0.1の2件(○率0%)と抑圧0.2の6件(○率100%)で
尤度がほぼ同じ(-1.41 と -1.52)だったこと。
どんな流暢さの統計量でもこの2群は分離できない。

## Phase 4 — 学習

報酬の検証を諦め、原理から定義して結果を人間が判定する方針に切り替えた。
進化戦略(対称サンプリング)、母集団12、母集団を1回の `generate` にバッチで詰める。

学習は4回失敗し、5回目で動いた。

| 回 | 変更 | 結果 |
|---|---|---|
| 1 | 初版 | 跳躍が第1世代から飽和。実質 `W_BAND`(事前知識)だけが駆動 |
| 2 | 天井・床の調整 | 40世代で報酬 -0.001。完全に平坦 |
| 3 | 同一乱数での対比較 | ノイズは19%しか減らず。抑圧で1トークン変われば先は別の文になる |
| 4 | **貪欲法で評価** | 報酬 +0.110(ばらつきの1.55倍)。初めて勾配が読めた |

貪欲法にすると報酬が回路の決定的な関数になり、対差 0.0916 がそのまま回路の効果になる。

ただし4回目の学習済み回路は**門をまったく使っていなかった**。

```
分岐点での実効抑圧   2.262
それ以外での実効抑圧 2.364   → 比 0.96
エントロピーとの相関 -0.140
```

type5 の正反対で、失敗した type6 と同じ振る舞い。
報酬のどの項も「分岐点だけを叩け」と要求していなかったのが原因。
ncps は `sparsity_mask`(配線そのもの)も Parameter として持っているため、
学習対象から外す必要がある点もここで判明した。

## Phase 5 — 盲検評価

### 第1回: 学習済みV2 は区別がつかない

```
条件        ○率
未学習      55%
学習済み     50%
制御なし     50%
```

特に良いとされた3件は各条件から1件ずつ。40世代の学習は検出できなかった。

### 第2回: type5 の前提を検証

選択性を報酬ではなく**構造**で保証した V3 を作り、
あわせて type5 固定の設定を条件に入れた。

```
条件         ○    ×   ○率   中国語  ラテン
type5固定   12    0  100%      0      0
V3未学習     7    5   58%      2      0
制御なし      7    5   58%      1      1
```

Fisher の正確検定で **p≈0.008**。4お題すべてで 3勝0敗。
素のモデルが 58% ということは4割方すでに外しており、
type5 はそれを 100% に引き上げている。壊さないのではなく良くしている。

## 最終試行 — 轍へ重心を移して分かったこと

type5 の設定を初期値にし、轍語彙をお題ごとの実測に変え、
轍の罰を世代とともに 0.3 → 1.5 へ重くした。

回路は**抑圧を 0.66 から 0.30 へ下げる**方向に学習した。

```
素の相関 (抑圧 vs 轍): +0.862
世代の効果を除いた相関: +0.498
  前半20世代の中だけ: +0.418
  後半20世代の中だけ: +0.835
```

これは観察ではなく対照実験である。進化戦略が回路を摂動して測り、
一貫して抑圧を下げる方向を選び続けた(対差は 0.169 → 0.436 と拡大)。

**抑圧を強めるほど轍語彙が増える。**

機構: 貪欲法の1位はしばしば機能語や平凡な継続で、それを押し下げると
内容語が繰り上がる。この領域の高確率な内容語とは
深淵・神秘・星・宇宙そのもので、抑圧は轍の語を優先的に引き上げていた。
判明2「轍は語彙でなく概念レベル」の数量化にあたる。

報酬を轍へ寄せた瞬間に回路が抑圧をやめたのは学習の失敗ではなく、
与えた目標に対する正解が「抑圧しないこと」だったということ。

## 手法上の教訓

- 抑圧幅に `round()` を使わない。量子化で選択圧が伝わらない
- 回路の初期状態は `settle()` で平均入力の定常状態にする
- 学習の評価は貪欲法で行う。サンプリングでは報酬がノイズに埋もれる
- ncps の `sparsity_mask` は学習対象から必ず外す
- 選択性は報酬ではなく構造で保証する。自由度を与えると退化解に落ちる
- 評価は盲検にする。条件やスコアを先に見せると判定が偏る
- 報酬に間接的な指標を足すたびに外れた。人間の判定で結果を見るほうが確か

## Phase 6 — 未来エントロピーによる重み付け

抑圧が失敗したのは、今の1位を押し下げると轍の内容語が繰り上がるため。
別の機構として、各候補について「それを選んだ次の分布がどれだけ開くか」を測り、
先が開ける候補を重くした。`s(w) = p(w) · Ĥ(w)^α`。
轍の語は定型句なので選んだ後の展開が限られ、自然に下がるはずだった。

計算量はKVキャッシュをバッチ方向に広げて1トークンだけ進め、
`batch_select_indices` と `crop` で戻すことで、1ステップ2回の順伝播に収めた。

盲検36件では未来エントロピーの脱出率が最高(55%)で、
轍語彙率も 2.37 → 1.40 と41%減った(p=0.045)。
しかし α を 0〜5 で振り、**同じ乱数種で対にする**と再現しなかった。

```
αと轍語彙率の相関: -0.085   (ほぼゼロ)
αと尤度の相関:     -0.864   (単調悪化)
対比較: α=1で4勝8敗、α=2で5勝7敗、α=3で8勝4敗、α=5で6勝6敗
```

この否定結果には力がある。同じ実験が尤度に対しては明確な単調効果を捉えており、
効果があれば検出できる設計だった。標本不足ではない。
盲検で出た p=0.045 は、多重比較補正後は 0.14 でしかなく、実際にノイズだった。

副産物として得たものが1つある。**人間の○が△より轍語彙が少ない**(69%, p=0.029)。
Phase 3 で41通り試して作れなかった「人間の判定を再現する指標」が
轍語彙率という形で手に入った……ように見えた。Phase 7 でこれが覆る。

## Phase 7 — 表現への介入

ロジットを操作する機構が2つ落ちた。共通点は
「次の1トークンをどれにするか」しか変えられないこと。
轍が概念レベルにあるなら出力の直前では遅い。中間層の隠れ状態に介入した。

方向ベクトルは、手元の結果212件をお題ごとに轍語彙率の中央値で二分し、
**お題の中で対比を取ってから平均**した。人手ラベルをそのまま使うと
お題の偏り(冬は1○7△)を拾い「朝・道具らしさ」を学んでしまう。

用量反応が出た。層24、強さは隠れ状態ノルムに対する割合。

```
強さ%   轍語彙率   尤度   0%と同一
  0     1.44   -1.43    12
  2     1.73   -1.37     1
  5     1.34   -1.46     0
 10     0.97   -1.46     0
 20     0.59   -1.70     0
 40     0.36   -2.21     0

強さと轍語彙率の相関: -0.419
```

5%以降で単調に減り、4お題すべてで同じ向き。10%では尤度がほぼ無傷のまま轍が33%減る。
出力も語彙の回避ではなく概念の移動に見えた —
冬の終わり→カレーの匂い、朝の匂い→靴下から漂うフケ、道具→黒い箱の旅。

### しかし盲検で否定された

4条件12件ずつでは介入20%が脱出率67%で最良だったが p=0.207。
条件を2つに絞り1条件32件に増やしたところ、**差は縮んだ**。

```
制御なし  13○ 17△ 2×   脱出率41%
介入20%  17○ 13△ 2×   脱出率53%   p=0.226

お題ごと
  青色     介入1○ 対 制御1○   p=0.767
  朝の匂い   介入6○ 対 制御6○   p=0.715
  道具     介入7○ 対 制御3○   p=0.059
  冬の終わり  介入3○ 対 制御3○   p=0.696
  道具を除くと 10対10          p=0.615
```

標本を増やすと差が縮むのは、12件時の25ptが上振れだったということ。
4お題中3つで完全に同数で、全体の差は「道具」1つから来ている。

## 結論

**3つの機構すべてが、轍からの脱出には失敗した。**

| 機構 | 客観指標 | 人間の判定 |
|---|---|---|
| 抑圧 | 轍が**増える** (+0.862) | 読みやすさは改善 (58%→100%) |
| 未来エントロピー | 効果なし (-0.085) | 未評価 |
| 表現への介入 | 轍が**減る** (-0.419) | **差なし** (p=0.226) |

3つ目だけは客観指標が動いた。それでも人間には届いていない。

**根本の誤りは、判明2 を語彙の指標で追いかけたこと。**
判明2 は「轍は語彙でなく概念レベル」と言っていたのに、
轍語彙率という語彙の指標を作り、それを減らす方向ベクトルを作り、
その指標で評価した。循環しており、指標が下がっても読み手には何も変わらない。

轍語彙(宇宙・神秘・深淵・星)を59%減らしても、読み手には同じに見える。
轍の正体は語彙ではなく、話の運び方そのものにある。

## 副次的な発見

**お題によって轍の深さがまるで違う。**

```
脱出率 (両条件あわせて)
  朝の匂い    75%
  忘れられた道具 62%
  冬の終わり   38%
  青色      12%
```

青色は何をしても出られず、朝の匂いは何もしなくても出られる。
これは介入手法より大きな効果で、**プロンプト側の設計のほうが
デコーディングや表現への介入より効くかもしれない**ことを示唆する。

## 手法上の教訓 (追加)

- 代理指標で作った介入を、同じ代理指標で評価しない。必ず盲検を通す
- 標本12件では、どんな効果も検出できない。最低30件は要る
- 用量反応は単発の有意差よりずっと強い証拠。ただし
  「作った指標での用量反応」は循環しうる
- 効果がある実験は、それを示す(Phase 6 の尤度 -0.864)。
  同じ実験が別の量に効果を出さないなら、それは標本不足ではなく本当に無効
