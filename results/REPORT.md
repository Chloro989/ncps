# センチュリオン Phase 0〜5 報告

2026-08-09

## 要約

**抑圧は「文章を保つ」には効き、「発想の飛躍」には効かない。**

盲検評価で、type5 の設定(エントロピー3.5以上の箇所でのみ上位2候補を -2.0)は
素のモデルの合格率 58% を **100%** に引き上げた。中国語もラテン文字も出さない。
一方、抑圧の強さと轍語彙の出現率の相関は **+0.862**。
抑圧を強めるほど轍語彙は**増える**。

目的の前半は達成、後半は機構ごと差し替えが要る、というのが結論。

---

## Phase 0 — 回路が入力を読めていなかった

type6 の ncps回路が定常状態に落ちていた原因を切り分けた。
定数入力を対照に引くと、観測される揺れの大半は回路自身の自律過渡で、
入力感度はそれを下回っていた。

```
出力      自律過渡   入力感度   感度比
強度      0.0922    0.0338    0.37
幅        0.0318    0.0274    0.86
```

抑圧幅は5つの初期値すべてで**一度も変化しなかった**。
`round()` で整数に量子化していたため、出力の変動が丸めで消えていた。

## Phase 1 — 実測でわかった3つ

Colab で 2012 トークン分の特徴を採取した。

- カスタム LogitsProcessor は **min_p より前**に呼ばれる(全語彙が生きている)。
  つまり抑圧すると `p_max` が下がり min_p の閾値も下がって候補が増える。
  抑圧は自分で自分の効果を増幅していた
- 特徴の分散は十分あった(entropy の標準偏差 1.658)。
  定常状態の原因は入力側ではなかった
- top1 と top5 の相関 0.838。4特徴のうち実質3つしか独立していない
- エントロピー3.5以上は全トークンの **24.4%**。
  type5 の門は「ごく一部」ではなく4分の1で発火していた

## Phase 2 — 回路の修正

4点直した。特徴の標準化と入力射影、出力ゲイン、抑圧幅の `round()` 廃止、
`settle()` による初期状態の定常化。

```
出力      自律過渡   入力感度
ゲート    0.0000    0.5877
強度      0.0000    0.1199
幅        0.0000    0.6264
```

自律過渡が厳密に0になり、入力感度は V1 の 3.5〜18倍になった。

## Phase 3 — 評価関数は作れなかった

24件の人手ラベルに対し、語彙・埋め込み・対数尤度のいずれも判定を再現できなかった。

| 手法 | 一件抜き正答率 | 多数派比 |
|---|---|---|
| 語彙ベースの新語率 | 逆相関 | — |
| 埋め込み距離(単調) | 逆相関 | — |
| 埋め込み距離(帯) | 70.8% | +16.6pt |
| 対数尤度(6統計量) | 62.5% | +8.3pt |
| 組み合わせ(41通り) | 66.7% | +12.5pt |

**× には2種類ある** — 轍型(流暢だが跳んでいない、尤度は高い)と
崩壊型(跳んだが読めない、尤度は低い)。単調な指標はどちらか一方を必ず取り違える。

決定的だったのは、抑圧0.1の2件(○率0%)と抑圧0.2の6件(○率100%)で
尤度がほぼ同じ(-1.41 と -1.52)だったこと。
どんな流暢さの統計量でもこの2群は分離できない。

## Phase 4 — 学習

報酬の検証を諦め、原理から定義して結果を人間が判定する方針に切り替えた。
進化戦略(対称サンプリング)、母集団12、母集団を1回の `generate` にバッチで詰める。

学習は4回失敗し、5回目で動いた。

| 回 | 変更 | 結果 |
|---|---|---|
| 1 | 初版 | 跳躍が第1世代から飽和。実質 `W_BAND`(事前知識)だけが駆動 |
| 2 | 天井・床の調整 | 40世代で報酬 -0.001。完全に平坦 |
| 3 | 同一乱数での対比較 | ノイズは19%しか減らず。抑圧で1トークン変われば先は別の文になる |
| 4 | **貪欲法で評価** | 報酬 +0.110(ばらつきの1.55倍)。初めて勾配が読めた |

貪欲法にすると報酬が回路の決定的な関数になり、対差 0.0916 がそのまま回路の効果になる。

ただし4回目の学習済み回路は**門をまったく使っていなかった**。

```
分岐点での実効抑圧   2.262
それ以外での実効抑圧 2.364   → 比 0.96
エントロピーとの相関 -0.140
```

type5 の正反対で、失敗した type6 と同じ振る舞い。
報酬のどの項も「分岐点だけを叩け」と要求していなかったのが原因。
ncps は `sparsity_mask`(配線そのもの)も Parameter として持っているため、
学習対象から外す必要がある点もここで判明した。

## Phase 5 — 盲検評価

### 第1回: 学習済みV2 は区別がつかない

```
条件        ○率
未学習      55%
学習済み     50%
制御なし     50%
```

特に良いとされた3件は各条件から1件ずつ。40世代の学習は検出できなかった。

### 第2回: type5 の前提を検証

選択性を報酬ではなく**構造**で保証した V3 を作り、
あわせて type5 固定の設定を条件に入れた。

```
条件         ○    ×   ○率   中国語  ラテン
type5固定   12    0  100%      0      0
V3未学習     7    5   58%      2      0
制御なし      7    5   58%      1      1
```

Fisher の正確検定で **p≈0.008**。4お題すべてで 3勝0敗。
素のモデルが 58% ということは4割方すでに外しており、
type5 はそれを 100% に引き上げている。壊さないのではなく良くしている。

## 最終試行 — 轍へ重心を移して分かったこと

type5 の設定を初期値にし、轍語彙をお題ごとの実測に変え、
轍の罰を世代とともに 0.3 → 1.5 へ重くした。

回路は**抑圧を 0.66 から 0.30 へ下げる**方向に学習した。

```
素の相関 (抑圧 vs 轍): +0.862
世代の効果を除いた相関: +0.498
  前半20世代の中だけ: +0.418
  後半20世代の中だけ: +0.835
```

これは観察ではなく対照実験である。進化戦略が回路を摂動して測り、
一貫して抑圧を下げる方向を選び続けた(対差は 0.169 → 0.436 と拡大)。

**抑圧を強めるほど轍語彙が増える。**

機構: 貪欲法の1位はしばしば機能語や平凡な継続で、それを押し下げると
内容語が繰り上がる。この領域の高確率な内容語とは
深淵・神秘・星・宇宙そのもので、抑圧は轍の語を優先的に引き上げていた。
判明2「轍は語彙でなく概念レベル」の数量化にあたる。

報酬を轍へ寄せた瞬間に回路が抑圧をやめたのは学習の失敗ではなく、
与えた目標に対する正解が「抑圧しないこと」だったということ。

## 手法上の教訓

- 抑圧幅に `round()` を使わない。量子化で選択圧が伝わらない
- 回路の初期状態は `settle()` で平均入力の定常状態にする
- 学習の評価は貪欲法で行う。サンプリングでは報酬がノイズに埋もれる
- ncps の `sparsity_mask` は学習対象から必ず外す
- 選択性は報酬ではなく構造で保証する。自由度を与えると退化解に落ちる
- 評価は盲検にする。条件やスコアを先に見せると判定が偏る
- 報酬に間接的な指標を足すたびに外れた。人間の判定で結果を見るほうが確か

## Phase 6 — 未来エントロピーによる重み付け

抑圧が失敗したのは、今の1位を押し下げると轍の内容語が繰り上がるため。
別の機構として、各候補について「それを選んだ次の分布がどれだけ開くか」を測り、
先が開ける候補を重くした。`s(w) = p(w) · Ĥ(w)^α`。
轍の語は定型句なので選んだ後の展開が限られ、自然に下がるはずだった。

計算量はKVキャッシュをバッチ方向に広げて1トークンだけ進め、
`batch_select_indices` と `crop` で戻すことで、1ステップ2回の順伝播に収めた。

盲検36件では未来エントロピーの脱出率が最高(55%)で、
轍語彙率も 2.37 → 1.40 と41%減った(p=0.045)。
しかし α を 0〜5 で振り、**同じ乱数種で対にする**と再現しなかった。

```
αと轍語彙率の相関: -0.085   (ほぼゼロ)
αと尤度の相関:     -0.864   (単調悪化)
対比較: α=1で4勝8敗、α=2で5勝7敗、α=3で8勝4敗、α=5で6勝6敗
```

この否定結果には力がある。同じ実験が尤度に対しては明確な単調効果を捉えており、
効果があれば検出できる設計だった。標本不足ではない。
盲検で出た p=0.045 は、多重比較補正後は 0.14 でしかなく、実際にノイズだった。

副産物として得たものが1つある。**人間の○が△より轍語彙が少ない**(69%, p=0.029)。
Phase 3 で41通り試して作れなかった「人間の判定を再現する指標」が
轍語彙率という形で手に入った……ように見えた。Phase 7 でこれが覆る。

## Phase 7 — 表現への介入

ロジットを操作する機構が2つ落ちた。共通点は
「次の1トークンをどれにするか」しか変えられないこと。
轍が概念レベルにあるなら出力の直前では遅い。中間層の隠れ状態に介入した。

方向ベクトルは、手元の結果212件をお題ごとに轍語彙率の中央値で二分し、
**お題の中で対比を取ってから平均**した。人手ラベルをそのまま使うと
お題の偏り(冬は1○7△)を拾い「朝・道具らしさ」を学んでしまう。

用量反応が出た。層24、強さは隠れ状態ノルムに対する割合。

```
強さ%   轍語彙率   尤度   0%と同一
  0     1.44   -1.43    12
  2     1.73   -1.37     1
  5     1.34   -1.46     0
 10     0.97   -1.46     0
 20     0.59   -1.70     0
 40     0.36   -2.21     0

強さと轍語彙率の相関: -0.419
```

5%以降で単調に減り、4お題すべてで同じ向き。10%では尤度がほぼ無傷のまま轍が33%減る。
出力も語彙の回避ではなく概念の移動に見えた —
冬の終わり→カレーの匂い、朝の匂い→靴下から漂うフケ、道具→黒い箱の旅。

### しかし盲検で否定された

4条件12件ずつでは介入20%が脱出率67%で最良だったが p=0.207。
条件を2つに絞り1条件32件に増やしたところ、**差は縮んだ**。

```
制御なし  13○ 17△ 2×   脱出率41%
介入20%  17○ 13△ 2×   脱出率53%   p=0.226

お題ごと
  青色     介入1○ 対 制御1○   p=0.767
  朝の匂い   介入6○ 対 制御6○   p=0.715
  道具     介入7○ 対 制御3○   p=0.059
  冬の終わり  介入3○ 対 制御3○   p=0.696
  道具を除くと 10対10          p=0.615
```

標本を増やすと差が縮むのは、12件時の25ptが上振れだったということ。
4お題中3つで完全に同数で、全体の差は「道具」1つから来ている。

## 結論

**3つの機構すべてが、轍からの脱出には失敗した。**

| 機構 | 客観指標 | 人間の判定 |
|---|---|---|
| 抑圧 | 轍が**増える** (+0.862) | 読みやすさは改善 (58%→100%) |
| 未来エントロピー | 効果なし (-0.085) | 未評価 |
| 表現への介入 | 轍が**減る** (-0.419) | **差なし** (p=0.226) |

3つ目だけは客観指標が動いた。それでも人間には届いていない。

**根本の誤りは、判明2 を語彙の指標で追いかけたこと。**
判明2 は「轍は語彙でなく概念レベル」と言っていたのに、
轍語彙率という語彙の指標を作り、それを減らす方向ベクトルを作り、
その指標で評価した。循環しており、指標が下がっても読み手には何も変わらない。

轍語彙(宇宙・神秘・深淵・星)を59%減らしても、読み手には同じに見える。
轍の正体は語彙ではなく、話の運び方そのものにある。

## 副次的な発見

**お題によって轍の深さがまるで違う。**

```
脱出率 (両条件あわせて)
  朝の匂い    75%
  忘れられた道具 62%
  冬の終わり   38%
  青色      12%
```

青色は何をしても出られず、朝の匂いは何もしなくても出られる。
これは介入手法より大きな効果で、**プロンプト側の設計のほうが
デコーディングや表現への介入より効くかもしれない**ことを示唆する。

## Phase 8 — プロンプトを変える

轍語彙(宇宙・神秘・深淵・無限・静寂・星)は、現行プロンプトの
「哲学や、美しいこと、不思議なことを語る」をモデルが最短距離で
表現した結果そのものだった。**川上から神秘を注ぎながら、
川下の機構でせき止めようとしていた。**

変種 B+D(接地 + 概念レベルの禁止 + 助力申し出の禁止を復活)を作り、
1条件32件で盲検にかけた。

```
現行  10○22△0×  脱出率31%  旧轍語彙率1.58
B+D  12○20△0×  脱出率38%  旧轍語彙率0.90   p=0.396
```

代理指標は43%減ったのに、判定は2件差。Phase 7 と同じ形。

禁止語の内訳が示唆に富んだ。**指示は半分だけ通った。**

```
宇宙 5→1   神秘 5→1   静寂 4→2   無限 1→0
深淵 4→4 (不変)      星 6→7 (増加)
```

禁止したのに増える語がある。「宇宙」を封じられたモデルが「星」へ逃げており、
判明2 で bad_words_ids について観察した迂回が、
概念レベルのプロンプト指示でも起きている。

### 禁止リストを長くすると、禁止が効かなくなる

迂回先(幻想的・生命)を足し、人物像に「知識と知恵、経験が豊か」を加えた
B+D2(8語禁止、262文字)を試した。

```
現行   15○15△     脱出率50%
B+D2  16○15△1×   脱出率50%   p=0.552

語ごと   B+D(6語)    B+D2(8語)
宇宙      5 → 1       3 → 2
神秘      5 → 1       5 → 6  ↑
深淵      4 → 4       0 → 3  ↑
```

**B+D で5分の1になった語が、B+D2 では減らず増えた。**
3Bモデルは指示を増やすと一つひとつを薄める。判明2 の迂回とは別の現象で、
指示の容量の問題。

### 測定系の限界に当たっていた

さらに重要な発見。**同じ「現行」プロンプトの脱出率が、回によって19pt動いていた。**

```
B+D の回:   10○/32 = 31%
B+D2 の回:  15○/30 = 50%      p=0.106
```

これまで追いかけてきた差は、すべてこれより小さい。

```
Phase7 表現への介入  +12pt  p=0.226
Phase8 B+D          +6pt  p=0.396
Phase8 B+D2         +2pt  p=0.552
```

**基準の揺れが効果より大きい。** ○△× の絶対評価では、
この規模の効果を原理的に捉えられなかった。
4機構が同じ場所で止まっていたのは、層の選択ミスではなく測定系の限界だった。

## Phase 9 — 一騎打ちと流動プロンプト

3つ同時に変えた。

**一騎打ち** — 同じお題・同じ乱数種の2出力を並べ、どちらが轍から遠いかだけを
選ぶ。絶対基準が要らず、回ごとの揺れが消える。符号検定で決着させる。

**お題を4から16へ** — 判明13 の通り青色と冬の終わりは何をしても20%で
天井を作っていた。感覚・物体・場面・時間・抽象の勾配を張った。

**流動プロンプト** — 生成ごとに姿勢2つ(9通りから)と禁止語3つ(12語から)を
選び直す。B+D2 の「増やすと薄まる」への処方で、一度に課す量を減らし、
出力群の全体では全部の轍を塞ぐ。平均194文字で現行161文字に寄せ、
流動性の効果を長さの効果から切り分けた。

### 測定系が機能した

```
流動 20勝 / 現行 12勝     符号検定 p=0.1077 (片側)
引き分け 0 / 両方崩壊 0 / 未判定 0
禁止語  流動18 / 現行21
```

**32対すべてで判定がつき、迷いがなかった。**
そして現行が両勝ちしたお題は1つもない(流動は4お題で両勝ち)。

有意には届いていない。**それでも流動を既定として採用した** —
点推定62.5%、一貫性、機構の説明が揃っており、
プロンプトはいつでも戻せるため判断のリスクが低い。
確定的な差ではない点は記録として残す。

### どの姿勢が効いたか(事後解析)

```
名前のある場所か人を、必ず一つ置く。            7勝2敗  78%
お題から始まる一つの具体的な場面を物語る。         8勝4敗  67%
誰かから聞いた話として語る。                 6勝3敗  67%
大きな言葉を使わず、小さなものの側から世界を見る。     4勝2敗  67%
知識と知恵、経験が豊かで、見てきたものの多さから語る。   4勝2敗  67%
──────────────────────────────────
音、手触り、におい、温度のうちどれか一つを必ず書く。    3勝3敗  50%
語るときは、目に見えるもの、手で触れられるものから始める。 2勝2敗  50%
特定の一日の、特定の時刻のことを書く。           3勝4敗  43%
```

**効いたのは「誰が・どこで・誰から聞いた」という物語の骨格で、
効かなかったのは「感覚を書け」という描写の指示。** これは予想と逆だった。
接地(五感)が鍵だと考えていたが、データは人と場所と伝聞を指している。

禁止語では新しく足した語のほうが成績が良い(囁く5勝0敗、彼方8勝3敗)。
逆に古参の轍語は効いていない(無限3勝5敗、象徴6勝6敗、星2勝2敗)。
**古い轍語はもう禁じても意味がなく、轍が別の語に移っている**可能性がある。

いずれも1句あたり4〜12対の事後解析で、選択の根拠には弱い。
句を絞るなら別途測り直すこと。

## Phase 10 — 会話をまたぐ姿勢の漂い

Phase 9 で流動プロンプトが勝ったが、句の選択は生成ごとに独立で状態がない。
液体回路の出番もなかった。複数ターンにすれば状態が生まれる。

**回路が勝つべき相手は固定プロンプトではなくランダム流動である。**
姿勢が変わるだけならランダムで足りる。回路が加えられるのは
変化の連続性だけ — ランダムは毎ターン独立に飛ぶが、
回路は記憶を持つので前のターンを引き継いで漂う。

仮説: 連続した漂いは一貫した語り手として読め、独立な飛びは不安定に読める。

学習は使わない。報酬は5回作ろうとして作れなかった。
連続性は回路の記憶による構造的性質として持たせる。

### CfC には状態を保つ項がなかった

ncps の CfC を default モードで使うと、隣のターンで共有する句は **0.44**。
ランダム選択の 0.46 と変わらない。記憶が働いていなかった。

原因は実装にある。`new_hidden = ff1*(1-t_interp) + t_interp*ff2` で、
ff1 も ff2 も毎ステップ `[input, hx]` から再計算される。
**前の状態をそのまま残す項がない。**
`ts`(歩幅)は `t_interp = sigmoid(t_a*ts + t_b)` という補間係数にしか入らず、
時定数として働かない。入力の強さを 0.1〜2.0 で掃いても共有句は 0.41〜0.44 で
動かなかった — 順位は倍率に対して不変なので、当然だった。

| 記憶の作り | 隣ターンの共有句 | 組み合わせの種類 |
|---|---|---|
| 素の CfC | 0.44 | 12.5 |
| CfC + 混合記憶 (LSTM) | **0.98** | **11.2** |
| 前ターンの姿勢を特徴に戻す | 0.65 | 11.0 |
| 混合記憶 + 姿勢戻し | 0.84 | 11.0 |
| (参考) ランダム / 固定 | 0.46 / 2.00 | — / 1 |

`mixed_memory=True` だけで連続性と多様性が両立した。姿勢を特徴として
戻すのは不要で、混ぜるとむしろ落ちる。

### LTC も試した。この用途では CfC+LSTM が上だった

LTC(Liquid Time-Constant)の ODE には保持項がある。
`v_pre = (cm_t*v_pre + gleak*vleak + w_num) / (cm_t + gleak + w_den)` で、
`cm_t*v_pre` が前の状態を残し、`cm_t = cm/(elapsed/unfolds)` なので
歩幅が本当に効く。入力依存のコンダクタンス `w_den` が実効時定数を動かす。

| 回路 | 漂い | 種類(最小) | 階段応答の緩和 |
|---|---|---|---|
| LTC 歩幅0.5 | 1.65 | 5.0 (2) | 4.75 |
| LTC 歩幅2.0 | 1.33 | 7.2 (2) | 2.88 |
| LTC 歩幅8.0 | 0.91 | 9.1 (6) | 1.62 |
| CfC + 混合記憶 | 0.91 | **12.5 (8)** | **3.75** |

**LTC は記憶と多様性を1本の軸で取引していて、両方は取れない。**
保持と入力感度が同じコンダクタンス分母を通るため、別々に調整できない。
LSTM は入力ゲートと忘却ゲートが分かれているので分離できる。

そして重要な否定的結果 — **「入力に応じて変わる実効時定数」は
姿勢選択の層まで上がってこない。** 段の大きさを 0.3→3.0 と10倍にしても
緩和は LTC 1.38/1.62/1.25、CfC+LSTM 3.88/3.75/4.00 で平坦だった。
液体性が下の層で動いていても、9個から2個を選ぶ離散化を通ると消える。

### 漂いだけでは記憶の有無を区別できなかった

LTC 歩幅8 と CfC+LSTM はどちらも漂い 0.91 で、この指標では同じに見える。
だが階段応答の緩和は 1.62 と 3.75 で、前者はほぼ記憶がない。
入力を切り替えたあと一定に保てば、記憶がなければ次のターンで落ち着く。
**受け入れ試験には階段応答を入れる必要がある。**

### 凍結の原因は基準の置き方だった

最初の作りでは16会話中14本で姿勢が凍結した。
偏差の可動域は 0.2945 あるのに、**順位を決める2位と3位の差は中央値 0.0314** —
可動域の1割で順位が決まっている。想定した特徴の平均が実測とずれていると
(長さが -1.08σ)、偏差の大部分が毎ターン同じ定数になって順位を固定する。

対策として1ターン目の応答で会話ごとに基準を置き直す作りも試したが、
**進みの特徴が 0.33→0.67→1.0 と単調に上がるため偏差の向きが毎ターン同じ**
になり、広い分布では逆に凍結が増えた(凍結0の種が 11/12 → 2/12)。
進みを外すとさらに悪化した(偏った分布で種類 7.3 → 4.8、凍結 3.3 → 7.5) —
進みは邪魔ではなく、偏った分布で唯一まともに動いていた特徴だった。

もう一つ分かったのは、最初の代用入力が壊れていたこと。
短文を重複なしで並べていたので語彙の豊かさが **1.00 ± 0.00** と完全に死に、
4つある特徴のうち1つを潰した状態で設計を選んでいた。
150〜250文字で内容語が繰り返される代用に直すと4つとも動いた。

### 回路の重みの種で結果が大きく変わる

24種を測ると漂い 0.66〜1.41、凍結 0〜5本と幅が大きい。
**後から良い種を選べば結果を見てからの選択になる。**
そこで条件を先に決め(漂い0.70〜1.60 / 種類8以上 / 凍結2本まで /
緩和2ターン以上)、種0から順に探して最初に通ったものを使う。
16/24 が通り、選ばれたのは種0(漂い1.19 / 種類11 / 凍結2本 / 緩和7ターン)。
`prot_type10_duel.py` は種を指定せず `find_seed()` を呼ぶ。

### 実験の設計

- 会話16本 × 4ターン。お題は巡回でずらして作り、16お題それぞれが
  4つのターン位置にちょうど1回ずつ現れる(ターン位置の効果が偏らない)
- **1ターン目は両条件で共通。** 始まりを揃えて差を2ターン目以降に絞る
- 禁止語は毎ターン両条件で同じ。生成の乱数種も同じ。動くのは姿勢の選び方だけ
- 回路の入力は自分の直前の応答から作る。閉じた輪になっている
- 生成112回、16対。片側の符号検定で12勝以上なら p<0.05

判定は2つ。**一貫性**(同じ一人の語り手として読めるか — 仮説の本体)と
**面白さ**(轍から遠く読み物として面白いか — 副作用の確認)。
一貫性で勝って面白さで負けるなら、それは安定と引き換えに飛躍を失っており、
目的からは後退になる。だから両方を見る。

### 第1回の結果 — 差が出ず、しかも仮説を試せていなかった

| 判定 | 結果 | p (片側) |
|---|---|---|
| 一貫性 | **引き分け13/16**、ランダム2 対 回路1 | 0.50 |
| 面白さ | 引き分け7/16、ランダム5 対 回路4 | 0.50 |
| 轍語(会話ごと) | 回路7 対 ランダム4、同数5 | 0.27 |

Phase 9 では32対すべてに判定がつき引き分け0だった。今回は16対中13対で
読み手が区別できなかった。**差が無いのではなく、差が見えない。**

理由は回路が実際に選んだ句を数えると分かる。

| 姿勢の句 | 回路 | ランダム |
|---|---|---|
| 断定を恐れず、言い切ってから離れる。 | **44** | 9 |
| 語るときは、目に見えるものから始める。 | 19 | 9 |
| 特定の一日の、特定の時刻のことを書く。 | 18 | 11 |
| 誰かから聞いた話として語る。 | 2 | 13 |
| 知識と知恵、経験が豊かで… | **0** | 11 |
| 大きな言葉を使わず… | **0** | 3 |

**「断定を恐れず」が回路の選択の92%(44/48)に入り、9句のうち3句は
一度も使われなかった。** 比べたのは「連続した漂い 対 独立な飛び」ではなく、
「1句を固定して残り1枠だけ動かす 対 ランダム」だった。仮説は試されていない。

### 受け入れ試験が見逃した理由

指標「組み合わせの種類」は、**同じ句を軸にした8通りとバラバラな8通りを
区別できない。** 92%集中している状態を「8種」として合格させていた。
Phase 8 以来くり返している型と同じ — 指標が2つの状態を区別できていない。

もう一つは作動点のずれ。実測応答112件から特徴を計算すると:

| 特徴 | 想定 | 実測 | 代用入力 |
|---|---|---|---|
| 轍語率 | 1.00±1.00 | 0.28±0.44 (**-0.75σ**) | 1.37±0.95 (+0.37σ) |
| 長さ | 1.00±0.40 | 1.27±0.27 (+0.63σ) | 1.37±0.16 (+0.92σ) |
| 豊かさ | 0.70±0.20 | 0.91±0.09 (**+1.09σ**) | 0.77±0.16 (+0.33σ) |

**平均が約1σずれ、変動は想定の半分以下。** これは偏差の大部分が毎ターン
同じ定数になり、順位がそれに固定される条件そのもの。
基準を引く修正は、基準の位置が実測と合っていて初めて効く。
想像で作った代用入力で受け入れ試験を通したことが根本の誤りだった。

### 第2回の準備

実測応答112件を `results/centurion_turn_responses.txt` に残し、そこから
正規化を決め直した(`FEATURE_MEAN = [0.5, 0.28, 1.27, 0.91]` /
`FEATURE_STD = [0.3, 0.44, 0.27, 0.09]`)。受け入れ試験の代用入力も
実測応答から引くようにし、**最頻句が選択の50%を超えたら不合格**という
条件を足した(ランダム選択なら1句あたり2/9=22%)。

較正後は種0が 漂い0.88 / 種類16 / 凍結1本 / 最頻句46% / 緩和2ターン。
第1回の実測(漂い1.31 / 種類8 / 最頻句92%)から大きく変わった。

## 手法上の教訓 (追加)

- 代理指標で作った介入を、同じ代理指標で評価しない。必ず盲検を通す
- 標本12件では、どんな効果も検出できない。最低30件は要る
- 用量反応は単発の有意差よりずっと強い証拠。ただし
  「作った指標での用量反応」は循環しうる
- 効果がある実験は、それを示す(Phase 6 の尤度 -0.864)。
  同じ実験が別の量に効果を出さないなら、それは標本不足ではなく本当に無効
- **絶対評価(○△×)は使わない。** 同じ条件の成績が回によって19pt動く。
  測ろうとしている効果より基準の揺れが大きければ、何を作っても同じ数字が出る
- **一騎打ちにする。** 同じお題・同じ乱数種で並べれば絶対基準が要らない。
  Phase 9 で初めて引き分け0・迷い0の判定が得られた
- **3Bモデルに指示を増やすと、一つひとつが薄まる。** 禁止語6個は効いたが
  8個では効かなくなった。増やすのではなく、少量を回す
- 機構を疑う前に測定系を疑う。4機構が同じ場所で止まったのは
  層の選択ミスではなく、測定系がその大きさの効果を検出できなかったため
- **ライブラリが名前どおりのことをしているか、式を読んで確かめる。**
  ncps の CfC(default) には状態を保つ項がなく、`ts` は時定数ではなかった。
  「液体」を名乗る実装を記憶があるものとして使っていた
- **指標が2つの作りを区別できないなら、その指標では選べない。**
  漂い 0.91 が LTC歩幅8 と CfC+LSTM で一致し、
  階段応答を測るまで記憶の有無が見えなかった
- **代用の入力が壊れていないか、統計を印字して確かめる。**
  語彙の豊かさが 1.00 ± 0.00 になっていて、4特徴のうち1つが死んでいた
- **乱数の種で結果が変わるなら、条件を先に書いて順に探す。**
  24種で漂い0.66〜1.41、凍結0〜5本。良い種を後から選ぶのは結果を見た選択
- **代用入力で受け入れ試験を通してはいけない。** 特徴の作動点が実測と
  1σずれ、変動も半分だった。基準を引く修正は基準が正しいときだけ効く。
  実測が取れるまでは「較正前」と札を貼って、本番を較正の1回目と数える
- **「種類が多い」は「偏っていない」ではない。** 組み合わせ8種のうち
  92%が同じ1句を含んでいた。分布の集中は、種類の数とは別に測る
- **引き分けが多い一騎打ちは、否定ではなく検出不能。** Phase 9 は
  32対で引き分け0、Phase 10 は16対で13。同じ道具でも操作の強さが違えば
  こうなる。引き分け率そのものが操作の強さの目盛りになる
